# 🟢 RK Raja XWD

WhatsApp + Telegram Control Center — Bulk Sender, Watcher, Master Lock

## ✨ Features

- 📱 **Bulk Sender** — Multiple groups + multiple phone numbers
- 🔒 **Group Name Lock** — Sirf matching naam wale groups me bhejo
- 🖼️ **Group Photo Lock** — Photo ke hisaab se filter
- 🚫 **Blocked Numbers** — Skip these numbers + their groups
- 🚫 **Blocked Group UIDs** — Skip these groups
- 🔐 **Master Lock** — Only owner can control
- 🔔 **Group Watcher** — Auto-message on name/photo change
- 🤖 **Telegram Bot** — Control from Telegram
- 🟢 **Green Theme + Custom Background**
